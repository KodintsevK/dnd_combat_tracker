Запуск проэкта происходит в 2 вариантах:
docker и отдельными сервисами.

1) Docker:

В корневой папке создайте файл окружения .env

В него поместите переменные:
Для сервиса постгри:
POSTGRES_USER="Имя пользователя"
POSTGRES_PASSWORD="Пароль юзера"
POSTGRES_DB="Название БД"

Для сервиса Бэкенда:
DATABASE_URL="Строка подключения к БД"
JWT_SECRET="Секретный ключ для геннерации jwt токена"
PORT="Порт на котором работает бэкенд"

Для сервиса фронтенда
REACT_APP_BACKEND_URL="Переменная адрес бэкенда куда идут запросы от фронта"
CORS_URL="настройка cors для бэкенда url"
CORS_PORT="настройка  cors для бэкенда port"
clientIP="Настройка для cors, если нужно прописать адресс вида http://mysite.com"
